# Roadmap

Direction, not commitments — items move between releases.

## 0.9.x — public launch line

- First-run polish: `brain doctor` catches every misconfig a newcomer hits
- Exemplar docs: README slim-down, examples/, FAQ (done in 0.9.1)
- Coverage and CI hardening (CodeQL, pytest-cov reports)

## Next

- Multi-repo context packs across indexed projects (today: per-repo scope)
- Graph v3 graduation: retire the dual-generation write/query split
- Deferred-payload retrieval UX in the web UI
- Smaller default footprint: optional services per tool (lite profile)

## Later

- Team features: per-user memory scopes, audit trails
- Managed hosting option for people who don't want a VPS
- Graph mining: architecture rule suggestions from coupling history

## Not planned

- Replacing your editor, your notes app, or your CI — Brain is the agent's
  memory and code index, and stays that.
